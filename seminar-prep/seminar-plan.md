# enode - 출품작 소개
- capability 기반 분산 실행 노드. 라고 하면 아무도 못 알아 들음.
- claude를 아무 머신에서나 실행해서 일을 시키거나 조사 결과를 전달받게 하는 cross-machine multi agent system.
- MCP와 다르게 각 머신 사용자가 간단히 자원을 등록할 수 있으며 중앙 서버에서 이를 중개함. 소비자는 runctl이라는 도구를 통해 원하는 cap 과 그를 바탕으로 한 계약을 제출할 수 있음.
- 보통 runctl을 부르는 소비자도 agent 이기에 mcp로도 제공함.
- 탄력 노드 개념이 추가되어 동적으로 오케스트레이터를 호출할 수 있음.
- 3단계 샌드박스 정책
- 등등 enode-demo.pen 캡쳐 붙여넣기
