# 결정표 — 이미 정해진 것. 다시 논의하지 않는다

이 표는 `features.md` 의 미정을 **착수 전에 값으로 닫은 것**이다. 게이트에서는
확인만 한다. 새로 묻지 않는다.

**게이트 규칙 한 줄 — 권장을 벗어나면 근거를 적는다.** 벗어나는 것은
허용이다. 근거 없이 벗어나는 것이 금지다.

```text
   1절   사용자가 확정한 것          값이다.  게이트에서 묻지 않는다
   2절   팩이 채운 권장값            값이다.  벗어나면 근거를 적는다
   3절   보안 확장 아래서의 취급      SECURITY 규칙마다 처리를 미리 적었다
   4절   이월                        이번에 정하지 않는다
   5절   정본에 되돌려 올리는 것      이 회차가 끝나면 진행자가 올린다
```

정본과 어긋나면 `enode-design/protocol/INVARIANTS.md` 가 이긴다 (`canon.md`).

```text
   정본이 이미 지는 값 — 팩이 고를 자리가 아니다

     매칭 기준 「부칠 수 있는가」          ADR-035 §2
     부칠 수 있는 것은 요구에 안 넣는다     ADR-035 §4.1
     MCP 탐지는 「설정에 있나」가 아니라 「뜨나」  ADR-035 §4.4
     키를 늘리고 매처는 안 고친다          ADR-035 §4.3
     팩은 blob 이다                       ADR-034 §2.2
     Fixed 는 Instrument 와 독립이다        ADR-034 §2.1
     계정 커넥터는 막고 Run 이 준 것은 연다  ADR-067 §2.1 (초안 — 5절이 결정으로 올린다)
```

# 2. 팩이 채운 권장값

| 항목 | 권장값 | 근거 |
|---|---|---|
| 홈 변수 | `CLAUDE_CONFIG_DIR=<계장 임시 디렉터리>/home`. `Fixed()` 가 값으로 박는다. `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1` 은 그대로 둔다 | `ADR-034` §2 · §2.1. 실측 D — 가짜 홈이 계정 커넥터와 개인 서버를 끊는다 |
| `--setting-sources ""` | 유지한다 | 실측 B · E — 이것이 개인 · 프로젝트 설정과 `.mcp.json` 을 끊는 층이다. 가짜 홈과 끊는 것이 다르다 |
| OAuth 자격증명 | 노드의 `~/.claude/.credentials.json` 이 있으면 가짜 홈에 복사한다. `0600` · 계장 임시 디렉터리와 함께 단계 끝에 삭제. 없으면 아무것도 안 한다 (환경변수 · 게이트웨이 노드) | `ADR-034` §3 ① 실측 — 홈을 옮기면 `Not logged in`. transparent 인증(R1 이 `HOME` 을 통과시키는 뜻)을 유지한다. 복사본이 임시 디렉터리 밖으로 안 나가고 같은 기계에 머문다. `Usable()` 은 실제 홈으로 재는 오늘 그대로 — 같은 파일이므로 광고와 실행이 어긋나지 않는다 |
| 허용목록 파일 | `<계장 임시 디렉터리>/mcp.json`. `{"mcpServers": {...}}` 모양. 플래그는 `--strict-mcp-config --mcp-config=<경로>` 등호 형태. 요청이 없으면 빈 목록 | `ADR-067` §2.1 이 기계를 지목했다. 등호는 `ADR-034` §3 ② 의 가변인자 함정 회피. 실측 C — strict 단독은 무변화라 파일과 함께 넘긴다 |
| 허용목록의 내용 | **6절 ⑥ ⑦ 이 뒤집었다 — 아래는 낡은 값이다.** ~~팩의 `mcp.json` 전부~~ + 노드 `mcp:` 중 `agent.mcp` 가 적은 것 + 워크스페이스 `.mcp.json` 중 `agent.mcp` 가 적은 것. 이름이 겹치면 팩 · 노드 · 워크스페이스 순으로 앞이 이기고 로그에 남긴다 | 세 출처가 있고 계약이 고른다. 팩이 이기는 이유 — 계약이 실어 보낸 것이 가장 재현 가능하다. **지금 값은 6절 ⑥(셋 다 `agent.mcp` 필터를 탄다)과 ⑦(노드 선언 이름을 팩이 덮으면 거절)이다** |
| 요청한 이름이 없을 때 | 하네스를 안 띄우고 단계를 실패로 보고한다. 사유 `mcp server <이름> is not available on this node` | `ADR-035` §3. 조용히 빼면 exit 0 으로 성공이 봉인된다 |
| 계정 커넥터 | 언제나 0. 여는 값이 없다 | `ADR-067` §2 — 노드를 나간다. 가짜 홈과 strict 가 두 겹으로 막는다. **첫 겹은 로그아웃 홈에서만 쟀다** — FR-1 이 `.credentials.json` 을 복사하므로 CA1 이 로그인된 홈에서 다시 잰다 (`application-design.md` 4.6) |
| 노드 선언 형식 | `enode.yaml` 의 `mcp:` 맵. `command` + `args` (stdio) 또는 `url` + `credential` (remote). 그 밖의 키는 그대로 허용목록에 옮긴다. **아는 키의 모양은 검증한다** — 틀리면 노드가 안 뜬다 (US-2 · U3 완료 조건) | `ADR-035` §4.4 의 모양 그대로. 하네스가 읽는 형식과 같아 옮겨 적기가 복사다 |
| 뜨나 | stdio — `command` 가 절대경로로 있거나 `PATH` 에서 resolve 된다. remote — `credential` 이름의 환경변수가 노드 환경에 있다. 연결은 안 한다 | `ADR-035` §4.4. 연결 확인은 광고마다 남의 서버를 두드린다 — 순연 |
| 탐지 자리와 주기 | 비싼 탐지(주기 장치 `Detector`, 기본 5분). **6절 ⑤ 가 이름과 종류 수를 고쳤다** — 인터페이스 이름은 `Fingerprinter` 이고(`Detector` 는 `ADR-068` 의 주기 장치가 쓴다) 종류는 하네스 · 저장소 · MCP **셋**이다 | `ADR-035` §4.2 · `ADR-068`. 실행파일 resolve 는 프로세스를 안 띄우지만 호출 수가 노드 설정에 비례하므로 값싼 쪽에 안 둔다 |
| 광고 키 | `mcp.<이름>: "1"` · `harness.<이름>: "1"`. 옛 `harness: <이름>` 은 한동안 같이 싣는다 — **걷는 시점은 이 회차가 안 정한다** (걷는 날 매처의 attrCount 가 노드마다 1 씩 줄어 정렬이 움직인다). 값은 언제나 `"1"` | `ADR-035` §4.3 · §6. 매처 무변경. 버전은 안 싣는다 (동등 비교뿐) |
| 자격증명 이름의 노출 | 광고에 `mcp.<이름>` 만 실린다. `credential` 의 환경변수 이름은 광고에 안 싣는다. 값은 어디에도 안 싣는다 | `ADR-035` §8 의 질문을 값으로 닫는다. 「그 기계가 Gerrit 자격을 가졌다」는 `mcp.gerrit` 으로 이미 드러나고, 변수 이름까지 실을 이유가 없다 |
| 워크스페이스 `.mcp.json` | 실행 시점에 읽어 요청된 이름만 허용목록으로 옮긴다. 광고하지 않는다. `project` 소스는 켜지 않는다 | `features.md` 3.4. 실측 F2 — project 소스를 켜면 저장소 설정이 통째로 딸려온다 |
| 워크스페이스 `.claude/skills/` | 하네스가 스스로 읽는지 CA5 가 잰다. 안 읽으면 팩으로 나른다 | 값이 아니라 실측 항목이다. 5절이 아니라 여기 두는 이유는 어느 쪽이든 문법이 안 바뀌기 때문이다 |
| 계약 문법 | `requires[].mcp.<이름>: "1"` (있는 문법) · `agent.mcp: [이름]` · `agent.pack: <blob 이름>` + `in.from` | `ADR-013` 결정 4 — 매칭과 실행을 가른다. `ADR-034` §2.2 |
| `agent` 의 알려진 키 | `model` · `max_turns` · `max_tokens` · `ask` · `harness` · `mcp` · `pack`. 그 밖은 `400` | `ADR-034` §5 ④. 오타가 조용히 사라지는 것을 막는다. 검증 자리는 `contract.Validate` — Mediator 와 enode 가 같은 패키지를 본다 |
| 팩의 형식 | tar 하나. 안에 `skills/<이름>/SKILL.md` · `agents/<이름>.md` · `mcp.json`. 그 밖의 파일은 무시하고 로그에 남긴다 | `ADR-034` §1.1 — SKILL.md 디렉터리 규약이 다섯 하네스에 공통이다. tar 인 이유는 blob 이 파일 하나이기 때문이다 |
| 팩의 출처 | 계약의 명령 단계가 `$OUT/pack` 에 tar 를 낸다 (`git archive --remote` · `curl -o` 등 argv 하나). `agent.pack` 이 그 이름을 적고 `in.from` 이 잇는다 | `ADR-034` §2.2 「새 부품 0 개」. 계약 인라인은 기각됐고 노드에 미리 두는 것도 기각됐다 |
| 오케스트레이터 | `cmd/iapadapter` 설정에 `executor.pack: { fetch: [argv], name: pack }`. 비면 오늘 그대로. 템플릿이 팩 단계와 `agent.pack` 을 더한다 | 사용자 확정 「전달 방향」. 계획이 짓는 단계는 문법 안내가 `agent.mcp` · `agent.pack` 을 알려주고 안 적으면 팩 없이 돈다 |
| 기록 | `HarnessResult` 에 `mcp: [이름]` 과 `pack: <sha256>` | `ADR-034` §5 팩 다이제스트 자리. `ADR-005` 성질 4 |
| 검증 수단 | `claude mcp list` 를 게이트에 쓰지 않는다. `-p --output-format stream-json --verbose` 의 `system/init` 줄로 잰다 | 실측 C · G — `mcp list` 는 strict 와 `--mcp-config` 를 반영하지 않는다 |

# 3. 보안 확장 아래서의 취급

`security-baseline` 이 켜져 있다. 규칙은 **차단성**이다. 규칙마다 처리를 미리 적는다.

```text
   SECURITY-01  전송 암호화     기존 코드 사실로 기록만.  수정 안 함
   SECURITY-03  로깅            기존 코드 사실로 기록만.  새 로그는 이름만 찍는다 —
                               빠진 MCP 의 이름 · 겹친 이름.  값은 안 찍는다
   SECURITY-07  네트워크        기존 코드 사실로 기록만.  새 포트 0
   SECURITY-08  접근 제어       새 표면에 적용.  허용목록이 곧 접근 제어다 —
                               계약이 요청하지 않은 서버 0 · 계정 커넥터 0.
                               노드 선언은 소유자만 쓰는 설정 파일에 산다 (ADR-063)
   SECURITY-12  인증 · 자격증명  새 표면에 적용.  가짜 홈의 자격증명 복사본은 0600 ·
                               단계 끝 삭제 · 임시 디렉터리 밖으로 안 나간다.
                               허용목록과 광고에는 이름만, 값은 없다.
                               R1 화이트리스트는 그대로다 — ENODE_TOKEN 은 안 넘어간다
```

**하지 말 것** — 보안 이유로 R1 화이트리스트를 넓히는 것. 계정 커넥터를 여는
값을 두는 것. 팩의 `settings.json` 을 읽는 것 (훅 설정이 정책인데 팩이 그것을
덮는다).

# 5. 정본에 되돌려 올리는 것

이 회차가 끝나면 진행자가 `enode-design` 에 올린다. 서브모듈은 진행자만 올린다.

```text
   ADR-067    초안 -> 결정.  §5 미결 둘의 답 —
              정책은 노드 설정(mcp:)과 계약 요청(agent.mcp)의 교집합에 산다.
              Run 이 MCP 를 요구하는 문법은 requires 의 mcp.<이름> 과 agent.mcp 다
   ADR-034    §5 「오늘 하는 것」 ①② 착수 기록.  §3 ① 의 OAuth 파일 복사 값.
              팩 tar 규약과 팩 단계.
              §3 ② 정정 — 「가변인자다 ⇒ 쓰지 않는다. MCP 는 홈의 파일로만 준다」가
              뒤집혔다.  등호 형태(--mcp-config=<경로>)로 쓴다.  안 올리면 정본에
              서로 반대인 두 문장이 남는다 (agent-runtime:836 과 ADR-067 §2.1 이
              둘 다 ADR-034 보다 늦게 그 플래그를 지목한다)
   ADR-035    §7 「지금 열지 않는다」 -> 열렸다.  여는 조건 충족 일자와 근거(사내 실측).
              §7 말미의 「detect.go 를 탐지기 순회로」가 이 회차에서 실행됐다.
              §8 첫째 · 둘째 질문의 답 — 매칭과 주입은 가른다 ·
              자격증명의 환경변수 이름은 광고에 안 싣고 노드 로그에만 남긴다
              (canon.md 3절이 올리라고 적은 값이다)
   agent-runtime R6   「스킬 · MCP 는 자리만」 -> 구현됨.  플래그 목록 갱신
```

# 6. 회차가 실측으로 교정한 것 (2026-09-11 · 09-12)

`v3-run-harness-components` 가 팩을 오늘의 코드에 대고 확정하면서 벗어나거나 고친
자리다. ① ~ ③ 은 Requirements Analysis, ④ ~ ⑤ 는 Application Design,
**⑥ ~ ⑭ 는 2026-09-12 의 설계 검증과 설계 질문**이 냈다. 근거 전문은
`aidlc-docs/v3-run-harness-components/inception/requirements/requirements.md` 7절과
`inception/application-design/application-design.md` 4절.

| | 항목 | 값 | 근거 |
