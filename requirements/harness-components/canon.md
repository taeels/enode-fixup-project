# 정본 — `enode-design` 과 이 팩의 연결

설계 정본은 이 저장소의 서브모듈 `enode-design/` 이다. **어긋나면
`enode-design/protocol/INVARIANTS.md` 가 이긴다.** 이 팩의 문서는 정본을
요약하거나 값을 채운 것이지 정본을 대체하지 않는다.

```text
   서브모듈 고정       gitlink 이 진다.  git ls-tree HEAD enode-design 이 답한다
   정본과의 거리       cd enode-design && git rev-list --count HEAD..origin/main
   갱신                git submodule update --remote 는 진행자만
```

# 2. 정본이 코드와 어긋나 있는 자리

**셋 다 「정본이 앞서고 코드가 뒤」다.** 이 팩이 그 거리를 없앤다.

```text
   ADR-034 §5      「오늘 하는 것」 ①(Fixed 의 홈 변수) ②(Instrument 의 tmp/home) 이
                   코드에 없다.  ③(max_budget_usd) 은 이 팩 밖.  ④(알려진 키) 는 이 팩
   ADR-035 §6 · §7  탐지기 순회 · mcp.<이름> · harness.<이름> 이 코드에 없다.
                   detect.go 는 아직 하네스 하나에서 break 한다
   ADR-067          초안.  코드에는 strict 도 mcp-config 도 없다.  --setting-sources ""
                   만 있어 실측 표(features.md 1.2)처럼 거꾸로 막는다
```

**`agent-runtime` R6 의 문장 하나가 낡았다** — 「닫는 기계는 위 목록에 이미 있다,
`--strict-mcp-config` 와 `--mcp-config`」. 기계는 있지만 코드가 안 쓴다. 이
팩이 끝나면 그 문장이 참이 된다.

# 3. 정본에 더하는 것 (역방향)

`decisions.md` 5절이 정본이다. 요약하면 **일곱**이다 — 아래 넷에 이 회차가 셋을 더했다 (`logs/` 의 내용을 못 박는
정본 여섯에서 ⑱ 이 벗어나는 것 · `ADR-005` 봉인의 잔여 표면 · `agent-runtime` R3 층의
갈래에서 ⑱ 이 벗어나는 것).

```text
   ADR-067      초안 -> 결정.  §5 의 답 둘
   ADR-034      §3 ① OAuth 파일 복사 값 · 팩 tar 규약 · 팩 단계
   ADR-035      §7 열림.  §8 첫째 · 둘째 질문의 값
   R6           플래그 목록과 「자리만」 문장 갱신
```

**실측 표는 정본에 함께 올린다.** `features.md` 1.2 의 표는 이 저장소가 잰 것이고,
`ADR-067` 이 「빈 파일을 주면 정당한 것까지 죽는다」로만 적어둔 자리를 네 줄로
채운다.
