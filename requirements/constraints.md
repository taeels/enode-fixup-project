## 제외 기능 (구현하지 않음)

### 1. 실행 중 선점
- 도는 Run 을 밀어내고 자원을 뺏는 것
- run 우선순위에 따른 자동 중단
- 선점 금지 옵션 (선점이 없으므로 금지할 대상이 없다)

근거 — `INVARIANTS` §2 가 `RUNNING -> RUNNING` 을 비멱등으로 두고 「재개하지
않는다」를 결정했고, 종료하면 Record 가 봉인된다(`I4`). 선점은 곧 진행분 폐기다.
`at-boundary` drain 은 단계 도중에 끊지 않는다 — 놓는 자리가 경계뿐이라는 것은
`INVARIANTS` §2 의 바닥이다. 놓인 Run 이 어떻게 끝나는지는 `decisions.md` 1절이 정한다.

### 2. 공정성 정책
- FIFO 외의 대기열 정책 (가중치 · 공평 배분 · 기아 방지)
- 정책을 갈아끼우는 틀
- 대기 상한 · 타임아웃
- 우선순위 (이월. `decisions.md` 4절)

근거 — `INVARIANTS` §1.2 의 `QUEUED` 행이 「대기열을 만들면 공정성 정책이
따라온다. 그건 값이 아니라 새 부품이다」로 예고했고, `ADR-002` 는 대기열을
「별도 ADR 로 연다」로 미뤘다. 부품 하나만 만든다.

### 3. 격리 강화
- OS 수준 샌드박스 (`sandbox: os`)
- 컨테이너 · VM 격리
- `run:` 단계의 도구 제한

근거 — `R7` 이 「하네스가 주는 만큼」으로 정했고 `ADR-042` 가 경계를 노드에 뒀다.

### 4. 인증

근거 — `ADR-015` §1 이 `principal` 을 식별로 두었고 자격증명 조사가 미완이다.
그래서 제어 표면을 노드에 둔다.

### 5. 실시간 스트림 · 트랜스크립트

- ~~노드 로컬 트랜스크립트 tail~~ — **2026-09-06 에 범위로 들어왔다**

## 구조 불변식 — 유닛을 어떻게 가르든 참이다

**여기 있는 것은 제약이지 계획이 아니다.** 어느 유닛이 무엇을 맡는지는
**Units Generation 이 정한다** — 이 팩은 그것을 미리 정하지 않는다.

### 임포트 금지 넷

```text
   internal/panel  ->  internal/store     금지.  제어판은 HTTP 로 Mediator 를 본다
   internal/panel  ->  internal/api       금지
   internal/api/ui ->  internal/store     금지.  화면은 정적 파일이다
   internal/enode  ->  internal/panel     금지.  데몬은 제어판을 모른다
```

**기계로 센다.** `go/parser` 로 각 패키지의 임포트를 읽는 **경계 검사
테스트**를 낸다. 그것이 첫 장면 게이트의 조건이다 — 겹침을 사람이 세지
않는다. 패키지 이름이 바뀌면 표도 같이 바꾼다. 검사기는 표를 읽는다.

**금지가 한쪽 방향뿐인 것에 뜻이 있다.** `internal/enode -> internal/panel`
만 막고 그 반대는 연다 — 제어판이 데몬의 함수를 쓰는 것은 괜찮고, 데몬이
제어판을 아는 것은 안 된다.

### 새 표면의 모양

```text
   새 기능은 새 패키지        기존 패키지에 밀어 넣지 않는다.  임포트가 얽힌다
   겉면은 얇게               Config · Server · New 로 끝낸다.  화면과 제어판은
                            관측 API 를 HTTP 로 부르고 store 를 직접 안 부른다
   api.go 는 등록 줄만       새 핸들러는 새 파일에 짓는다.  api.go 에는 mux 등록
                            한 줄만 는다 — 그 파일이 병목이 되지 않게
```

### Units Generation 에 거는 요구 하나

**파일 행렬을 반드시 낸다.** 유닛마다 만지는 파일을 표로 세고, 한 파일을 둘
이상이 만지면 그 자리를 접점으로 적고 처리를 정한다.

**행렬을 이 팩이 주지 않는 이유** — 그것이 그 단계가 결정할 일이기 때문이다.
미리 주면 단계가 옮겨 적기만 한다. 요구는 **산출물을 요구하는 것**이지
산출물을 대신 내는 것이 아니다.
