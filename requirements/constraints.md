# enode 기능 추가 예외사항 — 2판

이 워크샵에서 **구현하지 않는 것**이다. 요구사항 문서가 말하지 않은 것을
「빠뜨린 것」이 아니라 「뺀 것」으로 읽게 한다. 1판과 다른 곳은 §5 · §6 · §8
과 끝의 보안 확장 항목이다.

## 제외 기능 (구현하지 않음)

### 1. 실행 중 선점
- 도는 Run 을 밀어내고 자원을 뺏는 것
- run 우선순위에 따른 자동 중단
- 선점 금지 옵션 (선점이 없으므로 금지할 대상이 없다)

근거 — `INVARIANTS` §2 가 `RUNNING -> RUNNING` 을 비멱등으로 두고 「재개하지
않는다」를 결정했고, 종료하면 Record 가 봉인된다(`I4`). 선점은 곧 진행분 폐기다.
`at-boundary` drain 은 단계 도중에 끊지 않는다 — 놓는 자리가 경계뿐이라는 것은
`INVARIANTS` §2 의 바닥이다. 놓인 Run 이 어떻게 끝나는지는 `decisions.md` 1절이 정한다.

### 2. 공정성 정책
- FIFO 외의 대기열 정책 (가중치 · 공평 배분 · 기아 방지)
- 정책을 갈아끼우는 틀
- 대기 상한 · 타임아웃
- 우선순위 (이월. `decisions.md` 4절)

근거 — `INVARIANTS` §1.2 의 `QUEUED` 행이 「대기열을 만들면 공정성 정책이
따라온다. 그건 값이 아니라 새 부품이다」로 예고했고, `ADR-002` 는 대기열을
「별도 ADR 로 연다」로 미뤘다. 부품 하나만 만든다.

### 3. 격리 강화
- OS 수준 샌드박스 (`sandbox: os`)
- 컨테이너 · VM 격리
- `run:` 단계의 도구 제한

근거 — `R7` 이 「하네스가 주는 만큼」으로 정했고 `ADR-042` 가 경계를 노드에 뒀다.

### 4. 인증
- 중앙에서의 소유권 판정
- `principal` 을 인증으로 승격하는 것
- 다중 사용자 · 역할 기반 권한
- `GET /v1/nodes` 에 `principal` 을 내는 것

근거 — `ADR-015` §1 이 `principal` 을 식별로 두었고 자격증명 조사가 미완이다.
그래서 제어 표면을 노드에 둔다.

### 5. 실시간 스트림 · 트랜스크립트
- SSE · WebSocket 표면
- Mediator 를 통한 토큰 단위 트랜스크립트 중계
- ~~노드 로컬 트랜스크립트 tail~~ — **2026-09-06 에 범위로 들어왔다**
  (`decisions.md` 6절). 파일 tee 로 간다. 나머지 둘은 그대로 제외다

제어판의 「현재 작업」은 Mediator 조회로 채우고 데몬 로그를 읽지 않는다.
화면 S4 의 자리는 그대로 두되 **S3 의 트랜스크립트 카드가 살아난다** —
그 카드가 읽는 것은 노드의 링 파일이고 Mediator 를 거치지 않는다.

### 6. 배포 · 운영
- 대시보드의 인증 · 계정
- HTTPS · TLS · 리버스 프록시 구성
- 다중 Mediator · 고가용성
- 함대 자동 확장
- 페이지네이션 (`GET /v1/runs` 는 `limit` 만)

### 7. 기존 계약 변경
- `success_when` 문법 확장
- Record 봉인 규칙 변경
- 임대 키 변경 (`leases.node_id` 기본키)
- 새 상태 `READY` (`ADR-064` §1.1)
- drain 을 위한 중앙 라우트 (`POST /v1/nodes/{id}/drain` 류). 경로는 광고뿐이다
- `I1` · `I2` · `I4` · `I5` 를 건드리는 모든 것

### 8. 이번에 안 고르는 후보
- 역할 주입 (1판의 확정 ⑤. 2판에서 이월 — `decisions.md` 4절)
- ~~Mediator MCP~~ — **2판을 판 뒤에 범위로 들어왔다.** `decisions.md` 5절이
  전송(stdio)과 토큰 전달(환경변수)을 닫았다. 이 줄을 지우지 않고 남기는 것은
  「왜 밖에 있다가 안으로 들어왔나」를 다음 사람이 여기서 읽게 하기 위해서다
- 계정 MCP 커넥터 차단 · 노드를 나가는 도구 차단 (`ADR-065` 는 이제 관측 결정이고
  차단은 정본 `0fd304b` 밖의 열린 브랜치로 갈라져 나갔다. 이 저장소는 안 만든다)
- 장애 주입과 복구 검증. `QUEUED` 크래시 복구는 예외 — `decisions.md` 2절
- `colima-vm` 노드의 로그인 미검출 결함 (`Detect()` 가 로그인을 안 본다)
- 별칭 · 메모 (`ADR-063` §2 의 「자리만」)

## 보안 확장이 하는 것과 안 하는 것

`.aidlc-rule-details/extensions/security/baseline` 을 켠다. 규칙은 **새로 만드는
표면**에만 건다. 기존 코드의 사실은 기록만 하고 고치지 않는다 —
`decisions.md` 3절의 지침 줄이 그것이다. 위 §4 · §6 이 확장 때문에 되살아나지
않는다.
