| 개선 | 결과 |
|---|---|
| 웹캠 닫기/복원 | 헤더 닫기 버튼, 상단 웹캠 토글. 닫으면 iframe 제거·설정 요청 취소·이동 입력 정리. 늦은 응답이 플레이어를 되살리지 않는다. 다시 열면 크기·배율·pan 유지. 투어 시작 시 닫힌 웹캠 복원 |
| 한글 두 단어 | 한글 사전으로 `밝은 수달` 형태 생성. 기존 영문 이름을 결정적으로 이전하고 저장 키·온보딩 유지. 신규 제출은 한글 이름, 이전 미확인 요청은 영문 이름을 포함한 원문 그대로 재시도 |
| 플로팅 상세 닫기 | 노드·단계 상세는 바깥 클릭/포커스/휠/방향키, 보기·Run·필터 전환에서 닫힘. Escape/닫기 버튼은 원래 카드로 포커스 복귀. 내부 클릭·스크롤·폴링은 유지. 다른 카드 클릭은 그 상세를 즉시 연다 |
| 모달/투어 배경 | 배경에서 시작해 배경에서 끝난 클릭으로 닫힘. 내부 패딩·드래그는 닫기 원인 아님. 모달 닫기로 제출/미확인 요청을 취소하지 않으며, 투어는 건너뛰기와 같은 완료 처리 |

변경 파일은 `internal/api/ui/static/shared/guest.js`, `shared/fleet/view.mjs`,
`demo/{demo.js,demo.css,webcam.mjs,submission.mjs,tour.mjs}`와 Guest·제출 테스트다.
제출 계약의 한글 허용 형식과 이전 요청 호환을 담당 FD에도 반영했다.
공유 파일 `guest.js`는 nacl1119의 최신 원격 브랜치와 대조했다. 상대 변경은
상단 문서 경로 주석뿐이므로 이번 이름 동작 변경과 기능 충돌이 없다.
새 이름은 두 완성형 한글 단어, 공백 하나, 단어당 1~12자·최대 UTF-8 73바이트다.
이름은 인증 신원이 아니며 임의 입력 폼을 추가하지 않았다.

## 검증

- Node 전체 46 통과, 0 실패·스킵. 한글 이름 유지/영문 이전/쓰기 실패,
  신규 제출 형식·경계·이전 요청의 동일 payload 재시도 포함.
- Go UI `go test ./internal/api/ui -count=1 -cover`: 통과, 98.4%.
- 실제 api.Handler를 재시작한 Orca 브라우저에서 24개 동작 단언 통과.
  노드/단계 상세·바깥/내부 조작·관측 갱신·포커스·웹캠 복원·투어·모달 배경 포함.
- 실 함대 모드에서도 실제 인증 진입 후 노드 상세 열기·3D 전환 시 닫기를 확인했다.
- 모달 미확인 요청과 웹캠의 늦은 응답은 같은 브라우저 안에 만든 격리 인스턴스와
  테스트 전송으로 확인했다. 실제 공개 제출·방송 성공으로 기록하지 않는다.
