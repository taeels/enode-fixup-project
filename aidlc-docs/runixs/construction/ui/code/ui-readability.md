# 함대 탐색·정보 가독성 개선 결과

2026-09-09 팀원 피드백을 [변경 계획](../../plans/ui-readability-plan.md)에 따라
`unit/runixs-ui-readability`에서 구현했다. 기존 Code Generation의 보완이며,
전체 UI 유닛 완료나 공동 장면 승인을 새로 선언하지 않는다.

## 동작

**추가 피드백**: 3D 함대의 투영 간격은 가로 125→220, 세로 78→125로 넓혔다.
2D는 280×176 카드와 330×210 배치 간격을 사용한다. 이름은 영문/전각 문자 폭을
구분해 최대 두 줄로 표시하며, 넘치는 원문은 title·접근성 이름·상세에 보존한다.
긴 호스트명·한글 이름·긴 제출자로 1·2·3·6·12·24노드의 2D/3D 12가지 배치를
검증했고, 텍스트 겹침·SVG 잘림·2D 카드 넘침이 없었다. 기존 브라우저 45개 단언도
새 배치에서 다시 통과했다. 겹침 테스트와 일반 UI 테스트는 독립 초기 자료로 실행했다.

- 함대와 작업 그래프의 2D/3D에서 휠로 포인터 주변을 확대·축소한다. 수동 배율은
  15~300%, 화면 맞춤은 더 큰 그래프도 맞춘다. 가로 휠·Shift+휠과 스크롤바로
  이동한다. 정보 카드·Run 목록의 내부 스크롤은 장면 배율을 바꾸지 않는다.
- 작업 그래프는 장치 대신 순번·상태·용도·실행 노드가 있는 단계 카드와 needs
  화살표다. 3D는 깊이 있는 카드와 기존 배치를 사용한다. 별도 배경·헤더·작업
  제출자·현재 작업을 표시하고 함대로 돌아가기로 기존 배율·위치를 복원한다.
- 임대 대상은 현재 lease.run_id에 연결된 목록의 submitter다. 2D/3D 함대 카드와
  노드 상세에 표시한다. 목록 밖 Run과 빈 제출자는 각각 미확인/미제공이며,
  과거 assigned를 현재 임대로 해석하지 않는다.
- 노드 상세는 작업 수락·현재 작업/제출자, 제공 기능별 속성 표, 연결 시각,
  접힌 기술 상세 순서다. 알려진 키는 한국어로 설명하고 알 수 없는 키·값은
  보존한다. macOS·한국어·지원 형식 등을 읽기 쉽게 표시한다. sandbox는 광고값이다.
- 시각은 브라우저 시간대의 한국어 날짜로, 남은 시간은 초·분·시간 단위로 표시한다.
  원문은 time의 title과 기술 상세에 보존한다. 기존 서버 기준 시계·15초 freeze와
  ASKED의 임대 만료 예외를 유지한다. 목록·단계·질문 시각도 같은 형식을 사용한다.
- 기술 상세의 펼침·포커스·읽던 스크롤과 큰 배율의 장면 위치를 자동 갱신 중 유지한다.

## 변경 범위

`internal/api/ui/static/shared/fleet/format.mjs`가 시간·속성·현재 임대 제출자의
표시 변환을 담당한다. view·scene·fleet.css는 기존 구조에서 수정했다.
Node format 테스트를 추가하고 Go의 정적 모듈 서빙 검사에 format.mjs를 포함했다.
API·DB·폴링 클라이언트·토큰·공용 pen·다른 담당의 코드와 문서는 변경하지 않았다.

브라우저 검사는 휠 이벤트의 확대/축소·포인터 고정·상하한·내부 스크롤 분리,
화면 맞춤·보기별 위치·복귀 포커스, 단계 카드·분기 의미·목록 유지,
제출자 갱신·ASKED·HTML 문자열의 텍스트 삽입·시계 정지,
기술 상세의 깊은 스크롤·펼침·포커스 보존을 포함했다.
390px iframe에서 가로 넘침·복귀 버튼·헤더 겹침·정보 카드 줄바꿈도 확인했다.
실 함대 모드와 공개 데모 모드를 모두 검사했다. 선택된 QUEUED에 단계가 없어도
함대 복귀가 가능한 것을 확인했다.

로컬 재현 자료는 ignored `local/ui-readability-preview/`의 preview.mjs·checks.js·
browser-checks.json·node.png·graph.png다. 기존 obs-contract 합성 응답을 사용했다.
이는 물리 마우스/트랙패드 사용자의 실기기 검사나 실제 Mediator/DB 장면이 아니다.
Orca scroll 명령은 장면 wheel 이벤트를 발생시키지 않아 휠 증거로 사용하지 않았고,
브라우저 안에서 WheelEvent를 전달해 실제 DOM·SVG·스크롤 좌표를 검증했다.

검증 범위가 정적 UI이므로 DB 기반 전체 CP0와 실제 장비·LED·음원·방송 CP10은
이번에 실행하지 않았다. 기존 공동 장면 보류를 유지한다. UI 검사는 DB가 필요 없다.
향후 전체 장면 검사는 `scripts/testdb.sh`와 scene-gates·ci.yml을 따른다.
임시 정적 미리보기만 127.0.0.1에서 사용하고 검증 후 종료한다. 이전에 중지한
실제 Mediator·enode는 재시작하지 않았다. 사용자가 브라우저 확인 후 PR 제출을 요청하여 커밋·push·PR을 준비했다. main 병합·배포는 별도다.
