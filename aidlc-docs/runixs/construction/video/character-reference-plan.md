# 캐릭터 참조 시트 제작

2026-09-09 · runixs · 영상 제작 지원 산출물.

**현재 상태**: 과거 보류 계획. 이후 [전체 9종 시트](ddthon-all-character-sheets.md)와
[후속 영상](continuation-45s-plan.md)으로 이어졌다. 아래 미체크 항목은 당시 계획의
미완료 기록이며, 현재 영상의 새 대기 단계로 해석하지 않는다.

사용자가 처음 제시한 캐릭터가 Kling 영상 진행 중 달라지는 문제를 지적하고,
캐릭터별 시트를 만들어 입력에 함께 넣는 방향을 요청했다.
기존 영상의 재생성 요청으로 해석하지 않는다.

## 기준

- `ddthon-1.jpg`의 파란 기사, `ddthon-2.png`의 금색 기사와 흰 로봇 말이 원본이다.
- 첫 영상의 `kling-first-frame.png`는 초기 장면의 복장·스타일을 보완한다.
- 서대현님은 두 번째 채택본의 청록색 손·현대형 휴대폰만 참조한다.
  얼굴이나 전신은 새로 설정하지 않는다. 금색 동료와 별개다.
- 원본에 없는 뒷모습·완전한 전신은 추정해 보완한 검토용 디자인이다.

## 작업

- [x] 1. 원본·기존 드리프트·등장인물 역할·보류 결정을 확인.
- [x] 2. 캐릭터별 참조와 고정 특징을 정리하고 프롬프트 작성.
- [ ] 3. 내장 imagegen으로 개별 시트 생성·육안 검수·파일 저장.
- [ ] 4. 장면별 입력 매핑과 다음 Kling 제작 절차를 HANDOFF에 연결.

출력은 `output/enode-video/character-sheets/`에 저장한다. 이번 작업에서는
Kling 업로드·Element 등록·영상 생성 호출을 하지 않는다. 0–30초 채택본과
30초 이후 보류 결정은 유지한다. 제품 유닛 및 공동 게이트 상태는 유지한다.


**2026-09-09 보류**: 사용자 요청으로 queue 연동을 우선한다. 당시 산출물은 로컬에 보존했다. 최신 재개 기준은 [영상 인덱스](README.md)에 있다.
