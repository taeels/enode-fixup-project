## 장면 의도

파란 기사가 Galaxy S2 기기와 실행 가능한 개발환경을 찾는다. 금색 동료가
그 모델명을 듣고 오래전 과제라는 점에 놀란다. 이어 급한 이슈로 업데이트 바이너리를
돌려봐야 한다는 이유를 밝힌다. 마지막은 서대현님의 셋업과 휴가 사실로
마무리해 다음 장면의 원격 환경 연결 이야기로 이어간다.

과거 영상에서 쓰던 배역을 이어 파란 기사 02는 요청자, 금색 기사 06은 동료다.
동료는 서대현님이 아니다. 나머지 7종도 승인 기준으로 보관하며 이번 대화에는
두 캐릭터만 등장한다. 개발환경을 찾는 장면이므로 시작부터 S2를 손에 들고 있지 않는다.

## 고정 참조와 실제 입력

02 파란 기사 (`output/enode-video/character-sheets/ddthon-all-v1/02-blue-knight.png`),
06 금색 기사 (`output/enode-video/character-sheets/ddthon-all-v1/06-gold-charioteer.png`).

두 캐릭터를 각각 별도 이미지 Element로 준비한다. 표지는 시트의 정면 전신,
추가 이미지는 같은 시트의 3/4·측면·후면 전신을 쓴다. 시트에서 제목·표정 행·
옆 캐릭터가 섞이지 않도록 각 전신만 추출하며 몸체의 새 생성이나 재해석은 하지 않는다.
원본 PNG는 덮어쓰지 않고 추출본은 파생 파일로 보관한다.

정면 표지와 다른 각도의 추가 이미지 1–3개 구성은 공식 Element 가이드에 따른다.
시작 프레임에도 참조할 두 캐릭터가 모두 보이게 한다.
[공식 Element Library 가이드](https://kling.ai/quickstart/klingai-element-library-3-user-guide).

제작 재개 후 BLUE `320893737656451`, GOLD `320893745305789`를 이미지 Element로
등록하고 element_get으로 각도별 참조를 검증했다. 두 ID를 실제 제출 프롬프트와
elements 인자에 함께 연결했다. 음성 ID는 별도로 고정하지 않았다. 나머지 7종의
레지스트리 null은 미등록 상태를 뜻한다.

그 후 준비한 16:9 첫 장면을 first_image로 사용한다. 시트 전체를 시작 프레임에
넣으면 제목·다중 포즈·흰 배경이 장면으로 해석될 수 있으므로, 시트는 캐릭터
정체성 참조이고 첫 프레임은 두 사람이 개발실에 있는 장면이다. 이 구분은 본
제작에서 선택한 입력 설계다.

파란 기사는 회색 뿔 투구·분홍 볼·갈색 끈을 유지한다. 과거 대본의 붉은 깃털과
볼 장식을 없애라는 지시는 승인 시트와 모순되어 제거했다. 창은 오른손에서
정지시키고 왼손만 작게 움직여 소품과 몸체가 섞이는 동작을 줄인다.

## 조사에서 적용한 것

1. 캐릭터마다 같은 Element와 같은 호칭을 사용하고 화자를 대사에 직접 붙인다.
   시작 프레임과 별도 참조를 함께 쓰는 구성, 한국어 네이티브 오디오 지원은
   [공식 VIDEO 3.0 가이드](https://kling.ai/quickstart/klingai-video-3-model-user-guide)에서 확인했다.
2. 배경·등장인물·그림체를 먼저 정하고 각 컷에 시간·구도·행동·대사를 배정한다.
   요청·놀람·이유·단서 네 컷이 서로 다른 역할을 하도록 구성했다.
   [공식 Multi-Shot 가이드](https://kling.ai/blog/kling-video-3-multi-shot-guide).
3. 한 장소와 두 화자, 한 컷의 주동작 하나를 유지한다. 놀람 컷에만 작은 화면
   접근을 써서 표정이 중심이 되게 한다. 이는 위 가이드를 이 장면에 적용한 연출 판단이다.
4. 대사를 한글 발음으로 쓰고 S2는 에스투로 고정한다. 특히 첫 놀람과 짧은 쉼을
   구체화하고 나머지 컷은 작은 손짓과 시선 이동으로 제한했다.
5. 금색 기사의 놀란 표정을 살릴 수 있도록 투구 전체와 얼굴이 보이는 프레이밍을
   지정했다. 음성은 겹치지 않게 하고 현재 화자만 입을 움직이게 했다.
6. 화면 자막과 별도 로고는 후반 편집 대상으로 두었다. 기존 작업의 한글 UI 깨짐
   기록도 고려한 제작 판단이다. 의상의 기존 AI-DLC 표시는 유지한다.
7. 이미지 시트만으로 목소리까지 확정되지는 않는다. 이번에는 대사별 연기와 두
   목소리의 대비를 지정한다. 후속 편에서도 같은 음색이 필요하면 검수한 음성을
   지원되는 Character Element에 연결한다. 음성 연결이 된 뒤에는 프롬프트에서
   새 음색을 재지정하지 않는 것이 공식 권고다.
   [공식 VIDEO 3.0 가이드](https://kling.ai/quickstart/klingai-video-3-model-user-guide).
8. 제출용 프롬프트는 장면에 필요한 지시만 남긴 짧은 버전을 사용한다. 상세 연출
   메모는 별도 파일에 둔다. 현재 MCP는 prompt 최대 길이를 명시하지 않으므로
   특정 글자 수를 서비스의 확정 한도로 주장하지 않는다.

삼중 꺾쇠 참조에 함께 넣는다. first_image URL도 실제 업로드 결과로 바꿔야 한다.

원문에 가짜 ID가 남아 있는 템플릿을 그대로 실행하지 않는다.
