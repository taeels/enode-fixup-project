# Remotion UI 샘플 제작 계획

2026-09-09 · runixs · 지원 산출물. UI/demo-back의 공식 유닛 단계와 공동 게이트는 유지한다.

**현재 상태**: 별도 샘플의 보류 기록. 이후 완성한 720p 60초 영상은
[후속 계획](continuation-45s-plan.md)과 [검증 결과](code/build-and-test.md)를 따른다.
이 샘플의 마지막 미체크 항목을 후속 영상 완료로 소급 처리하지 않는다.

## 요청과 범위

직전 제안(공식 스킬과 로컬 프로젝트, 15초 UI 영상, 3초 노드 확대,
7초 모달, 한글 자막)에 사용자가 “응 한번 해주ㅝ”로 진행을 요청했다.
이번 승인은 해당 샘플의 설치·제작·미리보기·출력에 적용한다.

기존 `output/enode-video/HANDOFF.md`의 0–30초 채택본과 후반부 보류는 유지한다.
이번 샘플은 별도 `output/enode-video/remotion-ui-sample/`에 만든다.
Kling 호출·새 유료 생성·원격 게시 없이 기존 UI 캡처로 제작한다.

## 구성

| 시간 | 화면 | 전달 내용 |
|---|---|---|
| 0–3초 | 실제 3D 함대 UI 캡처 | 연결된 노드를 한눈에 |
| 3–7초 | Raspberry Pi 노드로 확대, 전체로 복귀 | 장비별 모형과 상태 확인 |
| 7–11초 | 실제 새 작업 모달 캡처 | LED·음원 시나리오 선택 화면 |
| 11–15초 | 2D 보기와 마무리 | 같은 함대를 다른 보기로 탐색 |

1920×1080, 30fps, 450프레임. 한글 자막과 가벼운 효과음.
노드·Run은 로컬 검증 데이터이며 UI 캡처를 애니메이션화한 샘플이다.
실제 POST 성공·하드웨어 실행·방송·CP10 통과를 표현하지 않는다.
