# 요구사항 — v2 시안 회차 (데모 공개용 현황판 pen.dev 시안)

## 의도 분석

- **요청**: mediator 현황판을 대중 공개 데모 페이지로 전환하는 화면들을 새
  pen.dev 시안으로 그린다. 사용자 원문은 `aidlc-docs/audit.md` (2026-09-08T07:25:47Z)
- **유형**: New Feature — 단, 산출물은 코드가 아니라 디자인 시안이다
- **범위**: 단일 산출물 — `design/enode-demo.pen` 아트보드 5장 (D1~D5)
- **복잡도**: Simple~Moderate. 기존 시안(`enode-ux.pen`)의 컴포넌트와 3D 뷰를
  재사용하므로 새로 발명하는 것은 데모 전용 요소(Guest 로그인 · 웹캠 · 투어 ·
  모달)뿐이다

## 질문 답이 닫은 값

| 질문 | 답 | 뜻 |
|---|---|---|
| Q1 | A | 새 파일 `design/enode-demo.pen`. `enode-ux.pen` 은 안 건드린다 |
| Q2 | X | 온보딩 카드 시퀀스(D0)는 다른 팀원이 만든다. 이 회차는 D1~D5 |
| Q3 | A | 웹캠은 실물 보드 함대를 비추는 라이브 패널 하나다 |
| Q4 | A | 3D 뷰는 S6 · S7 의 로우폴리 아이소메트릭 탑뷰를 그대로 이식한다 |
| Q5~Q7 | B·B·B | security 끔 · resiliency 끔 · PBT Partial (코드 없어 전부 N/A) |

## 흐름 (시안이 주석으로 남겨야 할 전제)

```text
   첫 방문      온보딩 카드 (D0.  타 팀원 산출물)  ->  데모 현황판 + 가이드투어 (D3)
   재방문      바로 데모 현황판 (D2)
   새 작업     D2 -> 모달 (D4) -> 제출 -> 작업 그래프 (D5)
```

## 기능 요구 — 아트보드별

화면이 있는 산출물이므로 각 장의 버튼을 전부 센다 (audit.md v1 요청의 규칙을
따른다).

### D1 — 데모 현황판 진입 (Guest 로그인)

- 기존 S0 의 Token 입력 자리를 **Guest 로그인** 버튼이 대체한다
- Guest 로그인이 이 브라우저에 `user_<번호>` 를 배정한다. 이름 사전은 없다
  (Functional Design Q2 에서 정정 — 2026-09-08. 원안은 랜덤 2단어 이름)
- 버튼: **Guest 로그인**

### D2 — 데모 현황판 본판

- 패널 넷이 한 화면에 산다
  - **웹캠** — 실물 보드 함대를 비추는 라이브 패널 하나
  - **노드 현황판** — S6 계열 3D 함대 탑뷰. 로우폴리 컴퓨터 모형 · 상태색 화면
  - **현재 작업 목록** — 진행 중 run 의 목록
  - **새 작업** — 모달(D4)을 여는 버튼
- 상단바에 게스트 이름 배지가 산다
- 버튼: **새 작업** · 상단바 뷰 전환 칩 (S6 이 이미 가진 격자 · 그래프 · 3D)

### D3 — 가이드투어 오버레이 (첫 방문)

- D2 위에 얹는 오버레이. 스텝 넷을 순서대로 하이라이트한다
  — 웹캠 -> 노드 현황판 -> 현재 작업 목록 -> 새 작업
- 첫 방문에만 나타난다. 조건은 시안에 주석으로만 남긴다 (구현 사양 아님)
- 버튼: **다음** · **건너뛰기**

### D4 — 새 작업 모달

- 화면을 덮는 모달에서 run 을 제출한다
- 계약을 적지 않는다. 미리 적힌 계약 둘에 대응하는 버튼 둘이다 (Functional
  Design Q1 에서 정정 — 2026-09-08. 계약 본문은 코드 회차가 적는다)
- 제출되면 작업 그래프(D5)로 넘어간다 — 전환은 주석으로 남긴다
- 버튼: **LED Toggle 작업 요청** · **사운드 재생 작업 요청** · **닫기**

### D5 — 작업 그래프

- S7 계열 3D 뷰를 얹는다 — 배정 단계에 로우폴리 모형 · 미배정 단계에 슬롯 마커
- **run 목록이 3D 뷰에 가려지지 않는 배치** — 목록과 그래프가 나란히 살고
  겹치지 않는다. 이것이 이 장의 수용 기준이다
- D2 의 틀 그대로다. 우 열의 run 을 클릭하면 좌 상단 3D 패널만 함대 뷰에서
  run 뷰로 바뀐다 (Functional Design Q3 · Q4 — 2026-09-08)
- 버튼: S7 이 이미 가진 것 (노드 · 단계 클릭 -> 상세 패널) + 뷰 전환 칩

## 비기능 요구

- **표기**: CONVENTIONS.md 1절 — 시안 안의 텍스트와 주석에 장식 문자를 넣지
  않는다
- **일관성**: 노드 카드(C1) · 상태색 · 3D 모형은 `enode-ux.pen` 의 것을
  재사용한다. 새 시각 언어를 만들지 않는다
- **정본 존중**: 필드 · 상태 · 값은 requirements 팩과 enode-design 정본에서만
  가져온다. 시안이 새 값을 발명하면 그 순간 설계와 갈린다
- **접근 수단**: `.pen` 은 pencil 도구로만 읽고 쓴다 (Read/Grep 금지)
- **파일 불변**: `design/enode-ux.pen` 과 `design/exports/` 는 이 회차에서
  변경하지 않는다
