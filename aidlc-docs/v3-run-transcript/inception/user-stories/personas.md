# 페르소나 셋

**새로 만들지 않았다.** 짝 팩(`v3-run-harness-components`)이 세운 셋을 그대로
잇는다 — 같은 제품의 같은 사람이고, 두 벌로 두면 이름이 갈린다.

**한 줄을 고쳐 쓴다.** 짝 팩은 P3 진행자를 「무엇을 쓰나: 없다. 이 팩이 만드는
표면을 안 쓴다」로 적었다. **이 팩에서는 거짓이다** — 진행자가 현황판을 연다.
`scene-gates.md` 1절의 장면 ③ 이 그 자리다.

---

## P1 노드 소유자

그 기계를 가진 사람이다. `enode.yaml` 을 편집할 수 있는 유일한 사람이고
(`ADR-012` · `ADR-015` §2), **그 기계에 무엇이 남는지 알아야 하는 유일한
사람**이다.

```text
   무엇을 쓰나     없다.  이 팩은 이 사람에게 적을 것을 안 늘린다
   무엇을 보나     제어판의 하네스 트랜스크립트 카드 (링 · 1초 폴링)
                  제어판의 지난 작업 (봉인된 것)
                  데몬 로그 카드 — 트랜스크립트와 다른 물건이다
   무엇을 모르나   링 파일에 무엇이 남는지.  오늘까지는 남는 것이 봉투 한 줄이었고
                  이 회차 뒤에는 사건 원문이다
   틀리면         카드가 안 자라는 것을 「단계가 멈췄다」로 읽는다.
                  또는 자기 디스크에 원문이 남는 줄 모른 채 기계를 남에게 넘긴다
```

## P2 계약 작성자

Run 을 내는 사람이다. `runctl` 로 직접 내거나 오케스트레이터가 대신 낸다.
**이 팩에서 이 사람은 새로 읽는 사람이 된다** — `GET .../log` 가 그 표면이다.

```text
   무엇을 쓰나     GET /v1/runs/{run}/steps/{seq}/log 의 from 과 as
                  (curl · 도구 · 스크립트)
   무엇을 보나     그 응답의 바이트와 총 길이.  as=events 의 사건 배열
                  runctl record 의 봉인된 묶음
   무엇을 모르나   지금 받은 것이 원문인지 선별본인지.  봉인 전후로 갈린다
                  자기 Run 의 도는 중 원문을 누가 더 읽을 수 있는지
   틀리면         from 오프셋을 그대로 이어 쓰다 엉뚱한 자리를 읽는다.
                  본문이 없는 것을 「에이전트가 아무 말도 안 했다」로 읽는다
```

## P3 진행자

회차를 돌리고 게이트를 집행하고 병합하는 사람이다. **이 회차에서는 유닛을
구현하지 않는다** — 그래야 `scene-gates.md` 2절 머리의 집행자 자격을 만족한다.

**짝 팩에서 고친 줄이 여기다.**

```text
   무엇을 쓰나     없다.  집행하는 사람이지 적는 사람이 아니다
   무엇을 보나     제어판과 현황판을 동시에 — CB4 가 「같은 시각 같은 문장」을 잰다
                  현황판 Run 상세의 단계 카드
                  봉인된 묶음 (runctl record).  조각 게이트 CB0 ~ CB6
   무엇을 모르나   현황판 카드가 안 자랄 때 그것이 청크가 밀린 것인지
                  단계가 멈춘 것인지
   틀리면         빨간 게이트를 초록으로 적는다.  짝 팩의 CP6 이 그렇게 닫혔고
                  사내 실측이 그 첫 눈이었다.  이 팩이 그 대가다
```

---

**셋 말고는 없다.** 「함대를 보는 사람」은 진행자의 한 얼굴이지 다른 사람이
아니다 (Q1 = A). 하네스 자신도 페르소나가 아니다 — 우리가 준 것만 읽는
프로세스이고, **이 팩은 그 프로세스가 뱉은 것을 사람에게 옮기는 일**이다.
