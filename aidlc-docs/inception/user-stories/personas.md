# 페르소나 — 3.4 온보딩 카드뉴스 + Guest Login

기존 일곱 기능은 이미 페르소나가 함축돼 있다(노드 소유자 · Run 제출자).
이 문서는 여덟째 기능이 새로 상정하는 페르소나 하나만 다룬다.

## 관람객 (event visitor)

- **누구인가**: 대회·행사 부스를 지나가는 사람. 개발보드를 안 만져봤을
  수도 있고, enode 라는 이름을 오늘 처음 들을 수도 있다
- **무엇을 아는가**: 없음. 「임대」 · 「drain」 · 「노드」 같은 팩의 어휘가
  배경 없이 온다
- **무엇을 원하는가**: 30초 안에 "이게 왜 필요한가" 를 감 잡고 싶다.
  깊이 배우러 온 것이 아니다 — 지나가다 멈춘 것이다
- **성공**: 카드 몇 장을 보고 데모 현황판을 마주했을 때 「아 이래서
  보드를 공유하는구나」 정도의 배경이 생긴다. 실패는 아무것도 안 남기고
  이탈하는 것이 아니라, 카드가 너무 길어서 다 안 보고 떠나는 것이다
- **이 페르소나가 안 하는 것**: Mediator 토큰을 안다 · 노드를 소유한다 ·
  실제로 계약을 제출한다. 셋 다 다른 페르소나(소유자 · 제출자)의 몫이다
