# U1 `transcript` — 논리 컴포넌트

**규칙 Step 6 의 둘째 파일이다.** 패턴은 `nfr-design.md` 가 든다.

---

## 1. 인프라 논리 컴포넌트 — **0**

| 컴포넌트 | 둔다 | 왜 |
|---|---|---|
| 큐 · 메시지 버스 | **안 둔다** | 비동기 경계가 0 이다. `Parse` 는 부른 자리에서 돌고 그 자리로 돌아온다 |
| 캐시 | **안 둔다** | 같은 입력에 같은 값을 내므로 **부르는 쪽이 캐시할 수 있다**. 파서가 상태를 들면 「시계를 안 받는다」가 깨지고 (Q3 = A) 시험이 비싸진다 |
| 서킷 브레이커 · 재시도 | **안 둔다** | 외부 호출이 0 이다. 끊길 것도 다시 부를 것도 없다 |
| 연결 풀 · 워커 풀 | **안 둔다** | 연결도 고루틴도 안 만든다 |
| 타이머 · 스케줄러 | **안 둔다** | 시계를 안 받는다. 경과는 화면이 뺀다 (`application-design.md` Q3 = A) |
| 속도 제한기 | **안 둔다** | 공개 엔드포인트가 0 이다. 그 자리는 U4 다 |
| 로거 | **안 둔다** | 로거를 받으면 본문이 로그로 샐 경로가 생긴다 (`nfr-requirements.md` 3절 SECURITY-03) |
| 메트릭 수집기 | **안 둔다** | 관측 대상이 아니라 **관측의 재료**다. 세는 값은 `Result` 가 낸다 (`Lines` · `Raw` · `Head` · `Partial` · `Elided`) |
| 설정 · 기능 플래그 | **안 둔다** | 값이 상수 둘(200 · 500)이고 팩이 진다. 바꿀 자리를 열면 화면 셋이 갈린다 |

**하나도 안 둔다.** `internal/transcript` 는 **표준 라이브러리만 쓰는 순수 함수
묶음**이고, 위의 아홉이 가리키는 물건이 이 패키지에 애초에 없다.

**이것이 `nfr-requirements.md` 3절의 N/A 여덟과 같은 사실의 다른 면이다.**
없는 것을 두면 그 자리가 곧 규율이 새는 구멍이 된다 — 캐시 하나가 「시계를 안
받는다」를, 로거 하나가 SECURITY-03 을 되돌린다.

## 2. 그래서 이 유닛의 구조물은 무엇인가

**컴포넌트가 아니라 형과 통로다.** `nfr-design.md` 2절의 패턴 셋이 논리 컴포넌트
자리에 앉는 것들이다.

| 자리 | 무엇이 앉나 | 무엇을 지나 |
|---|---|---|
| 읽는 통로 | `ParseLine` -> `Fields` -> `String` · `Bool` · `Int` | **하네스 JSON 을 읽는 유일한 길.** 우회를 형이 막는다 (B2) |
| 짓는 통로 | `Shell` -> `logShell` -> 바이트 | **껍데기를 짓는 유일한 길.** 목록을 타입이 든다 (B3) |
| 만나는 자리 | 한 패키지 · 왕복 시험 하나 | 짓는 쪽과 읽는 쪽이 갈리는 것을 막는다 (B4) |
| 경계 | `go list -deps` 의 금지 다섯 | 파서가 아래를 못 딛는다. 규칙이 아니라 의존 그래프다 |
| 세는 자리 | `Result` 의 다섯 값 | 관측을 밖으로 낸다 — 이 패키지가 스스로 관측하지 않는다 |

**부르는 쪽이 지는 것**을 함께 적는다 — 이 패키지가 안 두는 것을 누가 두나.

```text
   캐시 · 증분 읽기     U4.  GET log 의 from 이 그 손잡이다 (nfr-requirements.md 5.2)
   타이머              U5 (1초) · U8 (2초).  각자의 화면이 든다
   로깅 · 알림          U4 · U7 의 자리.  이 패키지는 재료만 낸다
   속도 제한           U4.  공개 엔드포인트의 것이다
```
