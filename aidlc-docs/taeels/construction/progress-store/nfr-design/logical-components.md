# U3 `progress-store` — 논리 구성요소

규칙 Step 6 의 둘째 산출물이다. 패턴은 `nfr-design.md` 가 진다.

**한 줄로 — 이 유닛이 들이는 인프라 구성요소가 0 이다.** 아래는 그 0 의 근거이고,
**있는 것 둘**은 이미 앞선 단계가 지었으므로 가리키기만 한다.

---

## 1. 안 들이는 것 — 규칙이 이름 지은 것들

규칙이 「queues, caches, circuit breakers, etc.」를 예로 든다. **하나씩 판정한다 —
빈 칸은 판정이 아니다.**

| 구성요소 | 판정 | 근거 |
|---|---|---|
| 큐 | **0** | 청크는 **노드가 민다** (`ADR-014` 결정 2). Mediator 쪽에 대기열이 설 자리가 없다 — PUT 하나가 파일 하나에 append 하고 끝난다. 밀린 것은 노드의 업로더 버퍼에 있고 그것은 U7 이다 |
| 캐시 | **0** | 읽는 쪽이 `from` 오프셋으로 **파일을 직접 읽는다**. 캐시를 두면 총 길이가 두 벌이 되고, `Total` 의 정의가 「파일의 크기」 하나인 것이 (R13) 그 자리에서 깨진다 |
| 서킷 브레이커 | **0** | 끊을 하류가 없다. 이 유닛의 바깥 호출이 **파일시스템 하나**다. 실패는 이미 보조로 떨어진다 (R25) — 브레이커가 할 일을 등급이 한다 |
| 재시도 래퍼 | **0** | 재시도는 **노드가 한다** — 실패한 청크를 다음에 이어 보내고 서버가 돌려준 총 길이로 오프셋을 맞춘다 (FR-5). Mediator 가 또 재시도하면 같은 바이트가 두 번 붙는다 |
| 백프레셔 · 요청 한도 | **0** | 이 유닛에 요청 표면이 없다. PUT 의 한도는 U4 의 자리이고 N1(함대 규모)이 그 값을 진다 |
| 워커 풀 | **0** | 쓰기가 호출자의 고루틴에서 그대로 돈다. 뮤텍스가 (run, seq, name) 별이라 (R28) 다른 단계끼리 안 기다린다 — 풀이 줄 이득이 0 이다 |
| 새 타이머 · 스케줄러 | **0** | 쓸기를 **이미 도는 `RunReaper` 에 얹는다** (V1 · V2). 주기를 두 벌로 두지 않는다 |
| 메시지 버스 · 이벤트 스트림 | **0** | `constraints.md` 1절이 SSE · WebSocket · 푸시 표면을 명시로 뺐다. 폴링이 표면의 성격을 안 바꾼다 (`ADR-025` §7 ③) |
| 외부 저장소 (DB · 객체 저장소) | **0** | `constraints.md` 6절이 DB 스키마 변경을 뺐다. 진행 파일은 **이미 있는 `Artifacts.Root` 안의 디렉터리 하나**다 |

**합 — 새 구성요소 0.** `tech-stack-decisions.md` 1절의 「고른 것이 0」과 같은 값을
다른 축에서 센 것이다.

## 2. 있는 것 둘 — 앞선 단계가 이미 지었다

**여기서 다시 설계하지 않는다.** 이 문서는 자리만 가리킨다.

| | 무엇 | 어디가 진다 |
|---|---|---|
| 1 | **단계별 뮤텍스** — 키 (runID, seq, name) · `Store` 의 필드 · 트리와 함께 죽는다 | Functional Design `domain-entities.md` 4절 · 규칙 R28 ~ R31 |
| 2 | **고아 쓸기** — `Reap()` 안 · 주기 60초 · 조건 둘이 배타 | NFR Requirements `nfr-requirements.md` 2절 (V1 ~ V3) · 규칙 R37 ~ R39 |

### 2.1 둘 다 「새 구성요소」가 아닌 이유

```text
   뮤텍스   표준 라이브러리의 sync 다.  인프라가 아니라 자료구조 하나다
   쓸기     **이미 도는 루프에 얹는 함수 하나다.**  새 프로세스도 새 주기도 아니다
```

**그래서 1절의 셈이 0 이다.** 둘을 구성요소로 세면 「새로 들인 것」과 「있는 것에
얹은 것」이 뒤섞여 다음 사람이 배포 그림을 다시 그려야 한다고 읽는다.

## 3. 배포 그림이 안 바뀐다

```text
   새 실행파일 0 · 새 포트 0 · 새 전송 0 · 새 자원 0
   진행 파일은 Mediator 가 이미 쓰는 record.Store.Root 에 산다
```

**`execution-plan.md` 가 Infrastructure Design 을 SKIP 한 근거가 이 줄이고**,
이 단계가 그것을 뒤집지 않는다. 스킵이 안 미룬 것 하나(디스크 값)는 **N2 가
이미 받았다** — `nfr-requirements.md` 4절의 봉투와 5절의 R40 ~ R42 다.
